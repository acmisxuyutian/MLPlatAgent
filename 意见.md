
意见1：Reproducibility is only partially supported. The authors state that the code and data are publicly available. I verified that the repository contains the source code, a SQL dump with the benchmark tables, and some instruction and checklist files. Therefore, I am not concerned that data were not released, but rather that the complete experimental artifacts described in the paper are not clearly identifiable in the public repository. Specifically, the paper states that DSEval-Kaggle-Ext contains 49 natural-language instructions, including UCI, CI, and MI instructions. However, the public repository only contains a small subset of these instruction files. The authors should either release the complete set of instructions and evaluation checklists used in the experiments or clearly explain what is and is not included in the repository.

意见2：The paper should clarify the availability of licenses and execution instructions. The repository lacks a clear license, and the reproduction protocol is insufficiently detailed. The authors should provide a license and exact setup instructions, as well as the required credentials, model versions, and random seeds, where applicable.
